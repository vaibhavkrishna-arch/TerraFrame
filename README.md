# TerraFrame

TerraFrame is a responsive image-search interface where users will be able to search for topics and browse matching images in a gallery. I chose a forest-green and warm-ivory palette to create a calm, nature-inspired identity that differs from typical purple search interfaces. The prominent headline and separate gallery section make the page's purpose easy to understand at a glance. Quick-pick topic chips and a visible empty-state illustration help first-time visitors know how to begin exploring.
